FAQ

Comment vendre sur Fidelity ?
  • Créer un compte gratuitement ici si vous n'en disposez pas qui sera valider par l'administrateur.
  • Apres la validation de votre compte vous aurez votre dashboard pour gerer vos produits.
  • Pour publier vos produits sur le site vous devez choisir un type de forfait : Mensuel ou par annonce
  • Une annonce parfaite est considérée comme ayant un titre approprié, une description claire, le prix et des images de l'article. Votre annonce sera publiée une fois le processus de modération terminé.
Quels sont les modes de paiement acceptés ?
  • Nous acceptons les paiements par carte de crédit, Orange money et mobicash.
Quelle est la politique de retour ?
  • Vous pouvez retourner les articles dans les 30 jours suivant l'achat, à condition qu'ils soient dans leur état d'origine.
Comment contacter un vendeur
  • Fidelity est une plateforme de petite annonce en ligne et qui permet de mettre en relation le vendeur et acheteur.
  • Pour acheter, vous pouvez contacter directement le vendeur de différentes manières :
    • WhatsApp - Cliquez sur l'icône WhatsApp disponible dans chaque annonce. Il ouvrira votre application WhatsApp avec le numéro du vendeur.
    • Utilisez l'icône telephone si vous souhaitez appeler directement le vendeur.
    • Utilisez l'icône sms si vous souhaitez envoyer de sms au vendeur.
